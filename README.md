# Timeaway — Employee Leave Management System

A Progressive Web Application (PWA) built to digitize and streamline employee leave booking, tracking, and management approvals across multiple organizations.

🚀 **Live Application:** [timeaway.vercel.app](https://timeaway.vercel.app)

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend & Auth:** Firebase (Firestore, Firebase Authentication)
* **Hosting & Deployment:** Vercel

---

## ✨ Key Features

* **Role-Based Access Control (RBAC):** Distinct permissions and UI views for employees vs. management teams.
* **Seamless Authentication:** Direct Google Sign-In powered by Firebase Auth.
* **Interactive Leave Calendar:** Dynamic scheduling dashboard to view, request, and track leave balances.
* **Management Review Portal:** Centralized dashboard for managers to approve, reject, and audit leave requests in real-time.
* **Progressive Web App (PWA):** Mobile-first, installable design for fast performance across desktop and mobile devices.

---

## 🏗️ Technical Highlights

* Engineered reusable React components to deliver a responsive, intuitive interface.
* Structured real-time Firestore database queries for immediate status updates and minimal latency.
* Implemented secure client-side routing and authorization guards for user role management.
